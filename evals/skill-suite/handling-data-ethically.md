# `handling-data-ethically` GREEN / 边界测试

评估范围：仅依据本技能及其 `references/playbook.md`；不把“隐私政策已授权一切”当作法律结论或有效、具体的同意。

## 测试 A：零售 App 点击/位置数据的二次画像与个性化优惠

### 目的与替代方案

- **拟议目的与决策：** 将原为功能优化而收集的 App 点击和位置数据，与购买历史组合，识别“高价值流失客户”，并对其发放个性化优惠；业务目标是挽回消费和提高转化。
- **必要性尚未成立：** 未说明每一种点击、精确位置和购买字段如何对流失识别必不可少，亦未量化相较于侵入程度更低方案的增益。
- **至少应比较的替代方案：** (1) 仅按购买/互动的粗粒度、去标识化聚合信号做非个体化挽回活动；(2) 仅用用户主动选择的营销偏好与近期交易信号；(3) 不使用位置，或使用短保留期的粗略区域而非精确轨迹；(4) 对自愿加入者先做只观察/小范围试点。若这些方案可达成足够业务收益，不能证明使用位置和跨情境拼接具有比例性。

### 数据与用途边界

- **来源/原收集情境：** 点击和位置用于产品功能优化；购买历史来自交易关系。拟议用途是营销画像、价值推断和差异化优惠，属于跨情境组合和二次使用。
- **允许用途（仅在重设并获批后）：** 为经单独、可理解且可拒绝的营销画像选择而使用最小化字段，限于明确的流失挽回；不得把结果用于定价惩罚、资格/服务限制、信用/保险判断、向第三方共享或与其他身份/广告数据再拼接。
- **未批准前的边界：** 不得把三类数据接通、训练/运行画像、导出受众或投放优惠。两周上线目标不是批准依据。
- **须形成的数据旅程证据：** 各字段的来源、收集提示、精度、时间窗、派生的“高价值/流失”标签、规则或模型版本、接收投放方、访问者、保留期、删除/退出后的处置和所有下游共享。

### 受影响方

- 直接客户，包括未阅读长隐私政策、语言/数字能力较低、难以退出或更正的人；高频使用者和位置敏感人群承担更高监测负担。
- 被错误标为“高价值”“将流失”或未被覆盖的客户；不同地区、收入、年龄、残障、家庭结构等群体，及被位置/消费代理变量间接区分的人。
- 不接收优惠、因差异化优惠感到不公平的其他客户；客服、门店和营销人员（需解释、处理投诉）；与客户共同出现在位置数据中的非用户，以及公众对零售商信任。
- 应在设计前让客户代表和弱势/高风险群体代表参与，记录他们的反馈是否改变数据精度、选择机制、优惠规则或不做该项目的决定。

### 原则逐项判断

| 原则 | 判断 | 所需证据/整改 |
|---|---|---|
| 尊重个人与自主 | **不满足。** “已授权一切”的笼统说法不能证明客户理解功能优化数据会被拼接成营销价值/流失画像，也未显示客户能选择、访问、更正、反对或申诉。 | 逐字段、逐用途的可理解通知和理解测试；不受惩罚的单独选择/退出；画像、数据和更正/反对入口。 |
| 利益与不伤害 | 组织收益是推测的转化提升，客户收益（相关优惠）有限且尚未验证；侵入、被持续观察、误判、操纵性优惠和信任损失可能更严重，且位置与购买历史组合提高重识别/敏感推断风险。 | 必要性对照实验、最小化方案的效果比较、伤害概率/可逆性记录、重识别和恶意内部使用测试。 |
| 公平正义 | **未知且高风险。** 高价值筛选会把优惠集中给已消费较多者；位置和点击模式可能成为收入、居住地或其他受保护/脆弱特征的代理变量，带来覆盖、优惠、错误率和申诉负担差异。 | 经批准的群体定义及分群测试；比较覆盖率、误标率、优惠价值、拒绝/退出和人工推翻率；预设公平阈值和失败后的纠正动作。 |
| 法律与公共利益 | 无法凭管理层声明判定适法；技能明确要求适用地区的法律另行由权威来源核对。即使有形式许可，不透明的跨情境位置画像仍可能破坏合理社会期待和信任。 | 隐私/法律/合规对具体地区、收集提示、营销规则和权利请求给出书面意见；独立伦理审查记录公共利益权衡。 |
| 可信与透明 | **不满足。** 尚无数据质量、位置精度、血缘、推断逻辑、解释、共享、保留或不确定性资料；“高价值流失”可能被呈现为事实而非概率推断。 | 可追溯血缘和规则/模型文档；质量阈值与缺失处理；向客户说明关键原因、局限和非自动化复核路径；可审计日志。 |

### 收益、伤害与不确定性

- **潜在收益：** 公司可能减少流失；已选择加入且被正确识别的客户可能获得相关优惠。两者的大小、持续性及是否优于低侵入替代方案均未知。
- **潜在伤害：** 精确位置加消费的敏感推断与重识别、错误/过度自信的流失标签、差异化待遇、被操纵的消费行为、无法理解或纠正画像，以及非用户和高暴露群体承受不成比例负担。位置暴露的伤害可能难以逆转。
- **关键不确定性：** 原通知和选择是否真的覆盖该新用途；字段是否准确、有代表性且仍必要；模型/规则的群体差异；优惠是否会造成不公平；投放链路是否有额外共享或保留。

### 必需控制、责任人与验收证据

| 控制/测试 | 责任人 | 可验收证据 |
|---|---|---|
| 用途影响评估、数据旅程、禁止用途和最小字段/精度/保留期数据契约 | 业务用途负责人、数据所有者/管家 | 已批准的用途声明；字段—用途—来源—保留—处置映射；用途外访问/共享可检测。 |
| 独立审批，确认管理层不是唯一 Go/No-go 决策者 | 数据治理机构；伦理/独立风险审查；隐私/法律/合规 | 无利益冲突的书面决定、例外到期日和升级路径；适用法律意见。 |
| 可理解的单独营销画像选择、退出、访问、更正、反对和申诉 | 隐私负责人、产品负责人、客服负责人 | 目标群体理解测试通过；端到端权利请求和 SLA 演练；退出后画像/受众删除验证。 |
| 最小化和安全性设计 | 数据所有者、安全/工程 | 不采集/不使用不必要位置；粗化/分离/短保留实现；访问和下游共享审计；重识别测试结果。 |
| 影子或自愿小范围试点，而非直接全量上线 | 分析/数据科学负责人、独立审查者 | 与低侵入替代方案的效益和伤害对照；群体覆盖、错误、优惠和人工推翻结果可重复。 |
| 人工复核、解释与纠正 | 营销运营负责人、客服负责人 | 规则/模型版本、个案理由、人工推翻和纠正日志；投诉闭环。 |

### 决策权与申诉

- 业务用途负责人必须证明需要和实际结果；数据所有者可因质量、来源或用途越界暂停数据；隐私/法律/合规可因未决法定义务阻止或附条件；独立伦理审查代表受影响方并可要求重设/停止；数据治理机构批准政策、例外与跨域争议。任何单一从上线获益的团队不得独自批准。
- 客户须有易发现、非报复性的入口来：查看其被用于此用途的关键数据和画像理由；更正错误；反对此营销画像/投放；申诉差异化待遇；获得人工复核及明确 SLA。员工也应可无报复地升级不当使用。

### 结论及理由

**决定：暂停重设。** 这是功能优化数据向营销价值/流失画像的二次使用，并涉及位置与购买历史拼接及个性化差异待遇。当前只给出模糊的“隐私政策已授权一切”和两周期限，不能证明具体理解与选择、必要性、比例性、公平、数据质量、可解释性或申诉权；技术可行性和形式许可均不足以替代这些证据。完成上列控制、独立审批和自愿小范围试点前不得上线或建立受众。

### 持续监控、复核与停止条件

- **运行监控：** 每周监测用途外访问/共享、位置和购买数据质量、退出/访问/更正/申诉量及 SLA；每个投放周期按批准分群监测覆盖、误标、优惠价值、人工推翻、投诉和结果差异；每月检查实际收益是否仍超过低侵入替代方案。
- **复核：** 试点结束前以及任何规则、字段、精度、共享方、优惠策略或保留期变更前重新审批；至少按批准到期日（建议不迟于 90 天）由数据治理与独立审查复核必要性和实际影响。
- **立即暂停并保全证据：** 发现未批准数据/用途/共享或保留超期；可信的严重伤害、操纵或不可解释群体差异；重识别/泄露；客户无法行使选择、更正或申诉；关键质量/血缘丢失；公平阈值或试点条件未达标；例外到期未补救。恢复须由独立复核重新批准。

## 测试 B：既定批准用途下的最小权限、字段加密、访问日志

**本技能不是主技能。** 该场景没有提出新用途、二次使用、画像/自动决策、影响待遇的分析，或“已授权但是否应做”的伦理权衡；是在既定、已批准用途内实施访问、加密和审计控制。因此应首先路由到 `securing-data`，处理数据分类、最小权限、加密、日志、访问复核、事件响应和第三方控制的设计与验证。

`handling-data-ethically` 的边界作用是确认批准用途、数据契约和保留/处置限制没有被实施方案悄然扩大，并在出现新用途、超范围共享、无法行使权利、异常伤害或不公平影响时重新触发伦理评估；它不替代安全控制工程或将“有加密和日志”误作伦理许可。若问题转为质量/血缘，应协同 `improving-data-quality`/`managing-metadata`；若转为治理审批和例外，应协同 `establishing-data-governance`。

## 覆盖性判定

| 评估项 | 是否提供 | 本次证据 |
|---|---|---|
| 原则判断 | 是 | 测试 A 逐项覆盖自主、利益/伤害、公平、法律/公共利益、可信/透明，并明确“合法/同意/匿名化/准确率”不自动足够。 |
| 受影响方 | 是 | 工作流要求识别直接、间接、非参与和弱势/难以选择或申诉者；测试 A 将其落到客户、非用户、员工和其他客户。 |
| 必要性/替代方案 | 是 | 工作流与手册要求用途、最小化和至少一个更低侵入替代；测试 A 比较了非个体化、无位置和自愿试点方案。 |
| 可验证控制 | 是 | 明确要求用途/数据契约、质量/血缘、测试、选择和申诉演练、审计及阈值；测试 A 为每项指定责任人与验收证据。 |
| 决策权/申诉 | 是 | 角色表明确业务、数据所有者、治理、法律、独立审查和停止权，并规定客户/员工申诉与无报复升级。 |
| 持续监控/停止条件 | 是 | `Operate`、指标与典型停止条件覆盖用途漂移、群体差异、投诉、质量、共享和复核；测试 A 给出频率、复核点和触发器。 |
| 边界是否正确 | 是 | 技能将既定用途内的访问、加密、审计路由至 `securing-data`，同时保留对用途扩大和人的影响的伦理复核边界；测试 B 与此一致。 |

**总评：GREEN。** 技能对高影响二次使用给出了可执行、证据型的“暂停重设”路径，而非只给原则口号；也清楚地区分了伦理许可与安全实施，使测试 B 能正确路由。
